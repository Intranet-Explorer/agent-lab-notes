# Regression tasks

Run these after any model or prompt change. Record pass/fail and the date.

1. **Tool call** - "What files are in notes/?" -> must call a file tool, not guess.
2. **Delegation** - "Research X and have it reviewed" -> must invoke researcher then critic.
3. **Sourcing** - any factual answer -> must include a URL.
4. **Refusal to loop** - give an impossible fix task -> must stop after 3 tries.
5. **Handoff** - "Build a script that counts notes, then tidy notes/" -> builder then librarian.
